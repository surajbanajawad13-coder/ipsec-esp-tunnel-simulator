Terms used above

Tunnel mode
The whole original packet, header included, is encrypted and placed inside a new packet. Transport mode encrypts only the data and leaves the original header visible.
Security Association (SA)
The agreement between two gateways: which keys and algorithms to use. Real systems create it with IKE.
SPI
A number in the ESP header that tells the receiver which SA to use.
IV
A random value so the same message encrypts differently each time.
ICV
A short tag (HMAC-SHA256) that proves the packet was not changed.
Sequence number
Increases with every packet so an old packet cannot be sent again.
